# Sales Analysis Dashboard

## Project Overview

This project analyzes sales data to understand business performance and generate meaningful insights using Microsoft Excel.

The analysis focuses on revenue performance, product contribution, regional performance, and salesperson effectiveness through an interactive dashboard.

## Objectives

The goal of this project is to:

- Calculate total revenue generated
- Identify top-performing products
- Analyze sales performance across regions
- Evaluate salesperson contributions
- Create an interactive dashboard for decision-making

## Tools Used

- Microsoft Excel
- Excel Formulas
- Charts and Dashboard Design
- GitHub

## Key Analysis Areas

- Revenue Analysis
- Product Performance Analysis
- Regional Sales Analysis
- Salesperson Performance Analysis

## Dashboard Features

The dashboard includes:

- KPI cards
- Interactive filters
- Revenue charts
- Product comparison
- Regional performance visualization
- Salesperson performance tracking

## Key Insights

- Laptop generated the highest revenue among products.
- Lagos recorded the highest revenue among regions.
- Sales performance varied across different products and locations.

## Recommendations

- Focus on high-performing products to maximize revenue.
- Investigate opportunities in lower-performing regions.
- Use sales insights to improve business decisions.

- Sales Data: Original dataset used for analysis
